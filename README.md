# Tymeline KiCad Agent

Public download page for the Tymeline plugin for the KiCad 10 PCB editor.

Each release attaches one install file, `tymeline-kicad-agent-<version>.zip`. This repository does not contain the plugin source.

## Install

1. Open [Releases](https://github.com/sayeed-hoda/kicad-plugin-release/releases) and download `tymeline-kicad-agent-<version>.zip`.
2. In KiCad 10: **Plugin and Content Manager → Install from File…**
3. Choose the zip, then **Apply Pending Changes**.
4. Restart KiCad, open a PCB, and turn on **Preferences → Plugins → Enable KiCad API**.
5. Click the Tymeline toolbar button and paste the `TYM1.` API key.

KiCad 10.0 is required.
